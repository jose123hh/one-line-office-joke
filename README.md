One office joke, one line, under 200 characters — the company hands out unlimited time off, only for the real limit to turn out to be the guilt trip from everyone who notices you took any. Entry for the make.fun bounty "Make the AI Judge Laugh: Office Jokes".

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (exactly the joke, one line, no trailing newline).
